# Temario para autorización de una Organización

Este documento no redacta cláusulas contractuales. Es una lista de temas que un abogado debe convertir en un acuerdo específico con cada Organización cliente.

Contexto informado por el proveedor: la Organización cliente actual es FEMUCARIBE. Este temario sigue siendo genérico para futuras organizaciones y no constituye por sí mismo autorización de acceso o uso de SIDC. La autorización concreta debe identificar el sistema y provenir de FEMUCARIBE o de quien tenga facultades para otorgarla.

- Identificación de las partes, equipos, sedes, responsables y alcance de la autorización.
- Autorización expresa para instalar, actualizar, ejecutar y desinstalar el shell en equipos definidos.
- Identificación del sistema institucional autorizado, autoridad que permite su uso y confirmación de que AegisDesk no modifica el ejecutable original ni recibe derechos sobre SIDC.
- Finalidades y campos minimizados de telemetría, confirmación de que el shell ya no envía `windows_user`, tratamiento de registros históricos, base jurídica, avisos y atención de derechos.
- Reglas para estado `active`, `disabled` y `revoked`, administración de ciclos, soporte y canal de recuperación.
- Roles de datos entre Proveedor, Organización, usuarios, Cloudflare, Resend y GitHub Actions.
- Acceso administrativo, grupos autorizados, trazabilidad, segregación entre organizaciones y gestión de credenciales.
- Tickets: categorías permitidas, advertencias, datos prohibidos, escalamiento, notificación y gestión de spam.
- Retención, eliminación, copias, exportación, investigaciones y devolución de información al terminar.
- Seguridad, incidentes, subencargados, transferencias internacionales, auditoría y cooperación.
- Soporte, niveles de servicio, mantenimiento, cambios materiales y reaceptación de términos.
- Suspensión, terminación, efectos locales, desinstalación, bloqueo, migración y devolución/eliminación de datos.
- Propiedad intelectual, avisos de terceros, límites de uso y responsabilidad conforme a la ley aplicable.

## PLACEHOLDERS PENDIENTES

- Organización, responsables, equipos y SIDC autorizados.
- Roles contractuales y bases jurídicas.
- Plazos, canales, niveles de servicio y procedimiento de incidentes.
- Revisión legal y aprobación de la versión final.

# Política de divulgación de vulnerabilidades

No incluyas vulnerabilidades, tokens, datos personales ni archivos de clientes en issues públicos o tickets ordinarios. Reportá de forma privada a **antonyml2016@gmail.com** con una descripción reproducible, versión afectada, impacto, evidencia mínima y una forma segura de contacto. Este es el correo general vigente; un alias dedicado de seguridad de AegisDesk queda pendiente de habilitar.

El equipo acusará recibo en **[PLAZO A DEFINIR]**, evaluará el alcance, coordinará una corrección y comunicará el estado cuando sea posible. Se solicita no acceder, modificar, borrar ni exfiltrar datos; detener las pruebas al confirmar el impacto. Los investigadores que actúen de buena fe y dentro de este alcance no deben causar interrupciones ni vulnerar la privacidad.

El alcance incluye el shell, instalador, Worker y pipeline publicados por este repositorio. No incluye el ejecutable original de SIDC, cuentas de terceros, infraestructura de clientes ni pruebas destructivas. Para un incidente activo, usá **antonyml2016@gmail.com** y, si se requiere atención inmediata, **+506 85456150**.
